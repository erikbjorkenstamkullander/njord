Njord n8n Kit

Snabbguide — Aderian CC IT

Klistrar du in njord-kit.js i en n8n Code-nod får du en komplett layout-funktion (njordPage()) och en uppsättning komponentfunktioner för att bygga snygga Business Central-sidor utan att skriva CSS.

Snabbstart — 3 steg

1

Klistra in kitet i en Code-nod

Kopiera hela njord-kit.js och klistra in i din Code-nod (JavaScript-läge). Filen fungerar som-den-är och returnerar en startsida direkt.

2

Hämta data i föregående nod

Koppla din HTTP Request-nod (webhook till BC API) före Code-noden. Data finns sedan i $input.first().json.

3

Bygg din sida med komponenterna

Skapa content-strängen med hjälp av funktionerna nedan, anropa njordPage() och returnera [{ json: { html } }].

Tillgängliga funktioner

njordPage({ nav, breadcrumbs, content, title })
Genererar en komplett HTML-sida med sidebar, topbar och innehåll. Alltid sista anropet.
njordSidebar(nav, activeCo)
Sidebar med logga, nav-grupper och company-switcher.
njordTopbar(breadcrumbs)
Topbar med brödsmula-navigation och bolagsindikator.
njordStatGrid([ { label, value, sub } ])
4-kolumnigt grid med statistikkort.
njordQuickGrid([ { label, href, iconKey } ])
Snabbvalskort i 4-kolumnigt grid. iconKey: customers, orders, invoices, crm, contracts, m.fl.
njordTable(cols, rows)
Stilad datatabell. Klickbara rader med _href i raden.
njordBadge(text, type, withDot)
Status-badge. type: success | warning | danger | info | neutral
njordAlert(text, type)
Infomeddelandefält. Samma typ-alternativ som badge.
njordBtn(label, href, variant, iconKey?)
Länkknapp. variant: primary | secondary | outline
njordPageHeader(title, sub?, actions?)
Sidhuvud med titel, undertext och valfria action-knappar.

Tillgängliga ikonnycklar

Använd dessa som iconKey i nav-items och quick-grid:

customersquotesorders invoicescreditscontracts overdueserialpurchases crmplussearch

Exempel — Listvy (Kunder)

Ersätt startsidans homeContent och njordPage()-anropet längst ner i kitet med:

// Data från föregående nod (HTTP Request → BC API)
const customers = $input.first().json.value || [];

const rows = customers.map(c => ({
  name:    c.displayName,
  no:      c.number,
  city:    c.city || '—',
  balance: (c.balance || 0).toLocaleString('sv-SE') + ' kr',
  status:  njordBadge(
    c.blocked ? 'Spärrad' : 'Aktiv',
    c.blocked ? 'danger'  : 'success',
    true
  ),
  _href: `/webhook/bc-customer?id=${c.id}&company=${co}`,
}));

const content = `
  ${njordPageHeader(
    'Kunder',
    company.name,
    njordBtn('Ny kund', '#', 'primary', 'plus')
  )}
  ${njordTable(
    [
      { label: 'Namn',   key: 'name',    width: '35%' },
      { label: 'Nr',     key: 'no',      width: '10%' },
      { label: 'Ort',    key: 'city',    width: '20%' },
      { label: 'Saldo',  key: 'balance', width: '20%' },
      { label: 'Status', key: 'status',  width: '15%' },
    ],
    rows
  )}
`;

// Markera rätt nav-item som aktiv
const nav = DEFAULT_NAV.map(g => ({
  ...g,
  items: g.items.map(i => ({ ...i, active: i.iconKey === 'customers' }))
}));

const html = njordPage({
  nav,
  breadcrumbs: [{ label: 'Kunder' }],
  content,
  title: 'Kunder',
});

return [{ json: { html } }];
